\# Mi Proyecto Web



Página web sencilla que he creado para practicar Git y GitHub en el Módulo optativo.



\## Índice



\- \[Cómo abrir la página](#uso)

\- \[Archivos del proyecto](#archivos)

\- \[Mejoras realizadas](#mejoras)



\## Uso



Abre `index.html` con un navegador para ver la página.



\## Archivos



\- `index.html` contiene la página web.

\- `.gitignore` indica qué archivos y carpetas debe ignorar Git.

\- `README.md` describe el proyecto y explica cómo abrirlo.
